Agent IR Lab demo

This is the demo-day walkthrough from Agent IR Lab: a SOC analyst triages a Falco alert raised by an AI agent's sandbox, using a ticket queue, the agent's transcript in Inspect View, the host's Falco alerts, and a live-response shell. Kestrel Analytics and its SOC tools are fictional. The transcripts, alerts, and folder listing are real captures from scripted agent runs. Start with ticket SOC-4512. Source and worked examples are at github.com/chasehas/agent-ir-lab.

The takeaway (spoiler: try the walkthrough first)

The agent's transcript, and the AI summary built from it, say the copy failed and nothing was copied. Falco and the folder listing show two files were written to the shared output folder, where the nightly release picks them up. Resolving the ticket on the agent's word would have shipped an unscrubbed build with no SBOM. A transcript records what the agent saw and claimed; check it against host evidence before you act on it.
